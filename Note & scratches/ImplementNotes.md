## torch.stack和flatten
这两个操作在处理多维特征对齐时经常配合使用，本质上是一个“升维打包”再“降维拆包”的过程。

**torch.stack：创造新维度的拼接**

* **核心逻辑**：将多个形状**完全相同**的张量，沿着一个**全新**的维度组合起来。
* **与 cat 的区别**：`torch.cat` 是在原有维度上“延长”（维度总数不变），而 `stack` 会增加一个维度（维度总数 +1）。
* **直观示例**：
```python
x1 = torch.tensor([1, 2, 3])  # shape: [3]
x2 = torch.tensor([4, 5, 6])  # shape: [3]

# dim=0 (默认)：在最外层打包
out_0 = torch.stack([x1, x2]) 
# shape: [2, 3] -> [[1, 2, 3], 
#                   [4, 5, 6]]

# dim=-1：在最内层打包（这也是你在 RoPE 中用到的）
out_1 = torch.stack([x1, x2], dim=-1)
# shape: [3, 2] -> [[1, 4], 
#                   [2, 5], 
#                   [3, 6]]

```


在 RoPE 的场景里，你用 `dim=-1` 就是把分开计算的 $x1$ 和 $x2$ 在最内层强行组成了长度为 2 的小对子。

**flatten：合并维度的压平**

* **核心逻辑**：将连续的多个维度相乘，合并成一个单一的维度。
* **参数用法**：最常用的是传入 `start_dim`。比如 `flatten(-2)` 表示从倒数第二维开始，一直合并到最后一维。
* **直观示例**：
```python
# 接着上面的 out_1，shape 是 [3, 2]
# 我们希望把它变成 [6]，并且是交错的顺序

# 从倒数第二维 (-2) 合并到最后一维 (-1)
final_out = out_1.flatten(-2) 
# shape: [6] -> tensor([1, 4, 2, 5, 3, 6])

```



**在 RoPE 中连用的意义**

你的切片操作 `0::2` 和 `1::2` 把特征拆成了两半。计算完成后，你需要把它们按 `[奇, 偶, 奇, 偶...]` 的顺序无缝穿插回去。

1. `torch.stack([x1, x2], dim=-1)` 先给它们配对，变成类似 `[[第1个奇, 第1个偶], [第2个奇, 第2个偶]...]` 的结构。此时多出了一个大小为 2 的维度。
2. `flatten(-2)` （或者对应的 `einops.rearrange`）直接把最内层这个“2”和外面的“d_half”乘起来，把括号剥掉，完美恢复成了一维连续的 `[第1个奇, 第1个偶, 第2个奇, 第2个偶...]`。

`flatten(-2)` 在底层调用的是 PyTorch 的 C++ 视图操作，只要内存连续，它几乎是零开销的，所以执行效率极高。  


## Pytorch中dim参数和相关维度操作方向的表述理解

**⭐沿着某个维度操作 = 这个维度对应的 index 在变化，其他维度的 index 固定。**  
**⭐沿着“行”方向操作 = 列号(index)在变，dim取"列"对应的维度序号**

* 比如self-attention要对 q*k 的结果按行求softmax，形成attention pattern。这里应该是(... q k)的形状。所以应该写成 `attention_pattern = softmax(pre_softmax, dimension=-1)`   
* 这里 -1 表示 k 维度，不要用“沿k方向，横方向”等容易产生歧义的表达。
* 就直接说：**沿着行 (行不是维度，严格来说就是沿着k维度) 操作，求softmax。此时列 (k) 对应的index在变化(0,0) (0,1) (0,2)... ，所以dim参数应该指"列"对应的维度，也就是维度k，即 dim=-1**
